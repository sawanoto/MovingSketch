# マーパン・ブレッドカタログ

パンの種類や焼き上がりによるマーパンの形・色・質感を、他のMovingSketchから再利用するためのカタログです。

## 現在のパン

| ID | 内部名 | 特徴 |
| --- | --- | --- |
| B01 | `burnt` | 上部の濃い焦げから下部のきつね色へ変化するグラデーション、通常マーパンと同じ三つ目 |
| B02 | `croissant` | ふっくらした弓形、巻き込んだ両端、層状の焼き目、中央が明るい焼き色 |
| B03 | `melon` | 通常マーパンの丸い形、明るい黄金色、メロンパンらしい斜め格子 |
| B04 | `toast` | 上部がふっくらした一枚切り形、香ばしい耳、明るく柔らかな白い生地 |
| B05 | `pizza` | 丸いピザ形、厚い耳、赤いソースの輪、チーズ、サラミとピーマン |

`bread-marpan.js` の `BreadMarpan` クラスは共有の `Marpan25D` を継承しています。視線追従、まばたき、横向き、表情指定を維持したままパン差分を追加できます。
