# MA-PAN MELODY MAZE

音列を縦方向の音高へ変換し、その形を正解経路にした短い迷路です。

- 入力: `const MELODY = ["C", "C", "G", "G", "A", "A", "G"]`
- 音高: C〜C5 の8段階を、下から上へ配置
- 経路: 同音は水平、高音は上、低音は下へ向かう直角の旋律骨格
- 迷路: 旋律骨格を固定後、22×15の全未使用セルをランダム化Prim法で接続
- 偽ルート: 盤面全域を覆い、各セルは一つの親だけを持つため正解経路の先へ再接続しない
- 操作: 矢印キー / WASD / 通路のマウスクリック / 画面下の方向ボタン

`SONGS` の音列を差し替えると、音高チェックポイント、旋律骨格、ダミー迷路の順で再生成されます。

## ステージ

- きらきら星
- かえるのうた
- チューリップ
- メリーさんのひつじ
- ちょうちょう
- ぶんぶんぶん

各ステージは曲を識別できる冒頭7〜8音を使用します。選択した音列から旋律骨格と22×15セルの迷路を毎回生成し、クリア済みステージは選択カードに星が表示されます。
