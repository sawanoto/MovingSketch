# マーパン無限ズーム

`index.html` をブラウザで開くと、マーパンが自動で転がり始めます。壁への衝突、ズームアウト、次のマーパンへの交代を操作なしで繰り返します。音はブラウザの制限により、最初のクリックまたはタップ後に有効になります。

本体と三つ目は `../shared/marpan-25d.js` の `Marpan25D.drawAt` を使用しています。共通描画へ画面上のピクセル寸法を渡すことで、輪郭や目の線幅を正しく描きます。右側のほぼ垂直な壁は、最初から16倍大きい次のマーパンの左端です。衝突後はその位置へズームアウトし、次のマーパンが姿を現します。段階ごとに座標とカメラを同時に正規化して、同じ構造を繰り返します。
