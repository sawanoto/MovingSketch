# 射的マーパン

腰浜神明神社のお祭りをイメージした、射的と音階演奏を組み合わせた作品です。`index.html` をブラウザで開いて遊べます。

- PC: マウスで照準、クリックで発射
- スマートフォン: 指で照準、タップで発射
- コルクは15発。棚から完全に落ちた景品だけ得点になります。
- 最下段の8体は左からド・レ・ミ・ファ・ソ・ラ・シ・高いド。命中時に音が鳴り、落ちた音階は以後演奏できません。
- RESTARTで初期状態に戻ります。

描画は `../shared/marpan-25d.js`、音階色は `../shared/marpan-note-colors.js` を使用します。後者は `27_MelodyFly4` の既存色を共通化したものです。物理演算は Matter.js、描画と音声は p5.js / p5.sound を使用します。音声は最初のユーザー操作で有効になります。
