# マーパン表情カタログ

4コマ動画などで使うマーパンの顔を、少しずつ追加・調整するためのフォルダです。

ページ上では表情をポジティブなものからネガティブなものへ並べ、左向き・正面・右向きの2.5D表示と、10色の体色による見え方を確認できます。表情IDはこの表示順に振り直しています。

## 現在の共有ライブラリで使える表情

| ID | 内部名 | 見た目・用途 |
| --- | --- | --- |
| F01 | `laughing` | ニコニコの左右目、丸い目枠内で白抜きのO口が開閉し、体が弾む大笑い |
| F02 | `happy` | 上向きの弧。ニコニコ、うれしい |
| F03 | `diamond` | ダイヤ形の輝く瞳。感動、夢中 |
| F04 | `smile` | 下向きの弧。穏やか、しみじみ |
| F05 | `shy` | 伏し目がちな三つ目、淡い頬の赤み、照れ線と小さな縮みで表す照れ顔 |
| F06 | `smug` | 角度の付いた左右の半目、中央の控えめな笑い口、余裕のある動きで表す得意げな顔 |
| F07 | `pupil` | 通常の黒目。視線移動が可能 |
| F08 | `surprised` | 三つの見開いた目と小さい黒目。純粋な驚き |
| F09 | `blink` | まばたき・閉眼。間、反応、考え中 |
| F10 | `sleepy` | 半分閉じた目。眠い、だるい |
| F11 | `beak` | 1つの目をくちばしへ変形。鳥への変身表現 |
| F12 | `signal` | 目全体が点灯。合図、機械的反応 |
| F13 | `flat` | 一文字の目。無表情、あきれ |
| F14 | `suspicious` | 三つの横目と左右非対称の上まぶた、ゆっくりした警戒の傾きで表す疑い顔 |
| F15 | `worried` | 困り眉風。心配、不安、圧迫時 |
| F16 | `flustered` | 不揃いに泳ぐ三つの黒目と、落ち着かない緩やかな身じろぎで表す焦り顔 |
| F17 | `confused` | 左右の渦巻き目、中央の泳ぐ黒目、迷うような動きで表す混乱顔 |
| F18 | `crying` | 左右を内向きの「＞＜」、中央を「へ」の字に閉じ、左右の涙と震えで表す泣き顔 |
| F19 | `fearful` | 左右の小さな恐怖目、丸枠内の白抜きの〇口、青い緊張線と縮こまる動きで表す恐怖の顔 |
| F20 | `angry` | 斜めのまぶた。怒り、真剣 |

## 表情以外に使える変化

- 三つの目を別々の表情にできる
- 視線を上下左右へ動かせる
- 目ごとに色、発光、点灯状態を変えられる
- 顔を左右へ向けられる
- 10色のカラーパレットで体色による印象の変化を確認できる
- 跳ねる、つぶれる、伸びる動きと組み合わせられる

## 今後追加したい基本表情

- ひらめき

顔文字そのものは使わず、絵文字のように「感情が一目で伝わる目の形・色・補助記号」としてデザインします。
