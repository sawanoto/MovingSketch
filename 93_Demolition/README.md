# マーパン解体工事（試作版）

`index.html` をブラウザで開いて遊べます。ドラッグで圧砕機を動かし、部材の上で押し続けるとヒビが入り、さらに圧砕すると破片になります。下層の柱を先に失うと支持バランスが崩れ、予兆の後に上部が崩落します。散水は粉塵と視界に影響します。

`building.js` は部材ごとの重量、柱の耐力・荷重・損傷・支持対象を管理します。上部重量を各階の生存柱に配分し、損傷した柱が限界を超えると時間差のある崩落へ移ります。崩落方向は失われた支持側で決まり、右側へ流れた部材がショベルカーに当たると操作不能になります。衝突しなかった場合は作業を続行できます。

部材は `attached → falling → fallen → gone` の状態で同じ配列に残ります。倒れた部材も角度を反映して当たり判定し、長い柱・梁や大きいコンクリート片は圧砕で短い部材へ分かれます。すべての部材が十分小さく砕かれたときだけ「解体完了」になります。崩落後に残った建物の支持力も再計算します。

`marpan-face.js` は `../shared/marpan-25d.js` の `Marpan25D` をそのまま小さな p5 キャンバスに描き、ショベルカーの運転席へ合成します。`game.js` は操作・圧砕、破片・粉塵・散水、生成音を担当します。部材には `material` と `kind` を持たせ、後の中型・小型機と廃材分別へつなげられるようにしています。

構造と半壊後の操作判定は `node building.test.cjs` で確認できます。
