# マーパンマインスイーパー — 音楽連鎖

`index.html`を開くと遊べる独立したミニゲームです。外部通信、インストール、外部音源は不要です。

## 遊び方

- 8×8の盤面に地雷12個。数字は周囲8マスの地雷数です。
- クリック / タップで開く、右クリック / 長押しで♪マークを付ける・外す。
- キーボードは矢印で移動、Enter / Spaceで開く、Fでマーク。
- 地雷を踏むと通常プレイは終了。その地雷から音楽の連鎖が始まります。
- 地雷を踏まずに安全マス52個を開くと成功。地雷が現れ、同じ全曲演奏へ進みます。
- 演奏が最後まで終わると「もういちど」が現れます。演奏中は盤面とリスタートをロックし、音ON/OFFだけ変更できます。

## 爆発が楽曲のタイムライン

曲は「きらきら星」全42音・48拍。冒頭12音は、盤面内の異なる12個の地雷が1音ずつ担当します。続く30音は、開始時から盤面を囲んで待機する30体の共通マーパンが担当します。

どの地雷を踏んでも最初の「ド」から曲を演奏できるよう、起点が決まった時点で冒頭12音を地雷の連鎖経路に割り当てます。近い地雷を優先し、最後は右端に近い地雷へ進みます。地雷はランダムに配置し、未開封マスの地雷・周囲数を画面へ表示しません。

1音目は踏んだ瞬間に発音・出現。音価に従って光の粒と音符が次の地雷へ移動し、到着した瞬間にその地雷が弾け、次の音が鳴ります。12音目からは盤面右端を通って右上の外周マーパンへ引き継ぎ、その後は時計回り。地雷の爆発、発音、ジャンプは同じイベントから開始します。すべてを一斉に発音しません。

成功時は左上側の地雷を起点にし、未演奏の地雷は淡い共通マーパンとして先に姿を現します。失敗時は未演奏の地雷を隠したまま、連鎖が到達するたびに出現します。常設の音名ラベルと旧「発見したメロディ」カードはありません。

別タブへ移動すると演奏を一時停止します。処理が遅れたフレームでは連鎖を遅らせ、音の省略や同時発音を防ぎます。音OFFでも連鎖は最後まで進みます。動きを減らすOS設定ではジャンプと飛び散る粒子を抑え、光で演奏位置を示します。

## ファイル

- `melody.js`：曲順・音程・音価。配色は46_Tower / 49_Invaderと同一。
- `engine.js`：地雷配置、数字、連続開放、マーク、成功 / 失敗、12音＋30音の経路。
- `game.js`：操作、時間管理、共通マーパン描画、波紋・粒子・光の移動、音。
- `style.css`：PCとスマートフォンに対応した盤面・外周レイアウト。
- `vendor/`：既存の共通マーパン・音響実装とp5.js 1.11.3をそのまま同梱。共通ファイル自体は変更していません。

## 検証

親フォルダから：

```sh
node --test 50_MineSweeper/tests/engine.test.cjs 50_MineSweeper/tests/interaction.test.cjs
```

100盤面の地雷数と数字、すべての起点からの音順・重複なしの経路、成功と失敗、長押しとスクロール、操作ロック、12音から30音への引き継ぎ、音と爆発の同時開始、最後の音が終わってからの再挑戦表示を検証します。
