# 88 — マーパン キラキラ

画面をタップ／クリックすると進み、4ページ目の次は最初に戻る絵本です。キーボードの Enter と Space にも対応します。

1. 共通マーパンの丸い輪郭と3つの目を星座として見つける。口は描かない
2. 星の自然な揺らぎの中、3つの大きな流れ星がマーパンの上を横断する
3. 星が温度に応じた青白・白・黄・橙・赤に色づき、強く明滅する
4. 約5秒で夜が明け、星と音が消えていく

星空と星座の位置は全ページで共通です。音は最初の操作後に有効になります。動きを減らす設定では朝への移行を短縮し、自動音を止めます。

`index.html` をブラウザーで開いてください。丸ゴシックは Google Fonts の Zen Maru Gothic を使用し、読み込めない場合は端末の丸ゴシック系フォントに切り替わります。
