# MA-PAN TOWER

マーパンを物理的に積み、塔を下から上へ読むことで選んだ曲を演奏するブラウザゲームです。

## 操作

- PC: マウス移動で位置を決め、クリックで落下。中央下のボタンで回転
- キーボード: `←` `→` で移動、`↑` で回転、`Space` で落下
- タッチ: マーパンを左右へドラッグして位置を決め、画面をタップして落下

## 曲の追加

`game.js` の `SONGS` に、表示名と `"ド"`〜`"シ"` の音列を追加します。

## 技術

- Matter.jsによる剛体物理
- Web Audio APIによる倍音付きサイン波音源
- Canvas 2Dによる描画・発光・粒子・カメラ追従
