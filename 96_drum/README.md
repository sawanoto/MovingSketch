# 太鼓マーパン

腰浜神明神社のお祭りをテーマにした、三つ目の和太鼓楽器です。太鼓の中央 75% で低い「ドン」、外周 25% で短い「カッ」が鳴ります。クリックとタッチの pointerdown に対応します。

描画には p5.js と `../shared/marpan-25d.js` の共通三つ目描画を使用します。音にはユーザー提供の `audio/don.mp3`（和太鼓でドン.mp3）と `audio/ka.mp3`（taikofuti.mp3）を使用し、Web Audio API で重ねて再生します。録音や譜面機能は含みません。

`index.html` をローカルサーバー経由で開いてください。
