# マーパン観察記 / Maapan Stories

三匹のマーパンに個体差・欲求・記憶を与え、生活から起きた出来事だけを材料に、一日の終わりに短い観察記を作るプロトタイプです。第2段階では「眺め続けるゲーム」から、物語の種を一つ投入して三匹の答えを見る、短い実験のゲームへ変更しました。

## 一日のゲームループ

朝は4秒だけStory Seedを受け付けます。何も選ばなければ自動的に「何もしない」として約24秒のシミュレーションが始まり、結果画面で止まらず翌日へ進みます。毎日の観察記は履歴へ保存し、ポップアップは10日ごとの「十日間の観察記」だけです。速度変更は残していますが、通常速度でも連続して日々が積み重なる設計です。

Story Seedは、木の実ひとつ、たくさんの木の実、大雨、謎の卵、不思議な音、新しい場所、何もしない、をデータとして定義しています。日数で順に解放されます。Seedが決めるのは世界条件だけで、結果は個体差・欲求・記憶・関係・位置・他個体・乱数から毎回採点します。

## 既存仕様の利用

- 描画は `../shared/marpan-25d.js` の `Marpan25D` を直接利用しています。輪郭、三つ目、視線、瞬き、表情、色の扱いを再定義していません。
- 遺伝情報は同ファイルの `MarpanDNA` を利用しています。各個体は固定IDと128塩基のDNAを持ち、保存後も同じ個体です。
- リポジトリ検索時点では、個体値を行動へ接続する既存実装は `MarpanDNA` 以外にありませんでした。そのためDNAを置き換えず、DNA断片の決定的ハッシュを行動傾向へ解釈する薄い層だけを追加しました。

## 性格と行動選択

DNAから好奇心、社交性、警戒心、食欲、活動性、執着、協調性、気分の変わりやすさを派生します。色と性格は無関係です。

各個体は一定間隔で候補行動を採点します。採点材料は性格、現在の空腹・疲労・一緒にいたい気持ち、天候と物の状態、相手との関係、具体的な過去の記憶です。Seed投入直後は候補の反応価値を上げる「事件発生圧」が働きますが、結末や喧嘩を固定するものではありません。選択した理由は個体をタップする「頭の中」と、重要ログの「なぜ？」から確認できます。

## 記憶と関係

記憶は日時、対象、行動、内容、強度を持つ具体的な出来事として保持します。木の実を譲った／もらった、同じ場所で雨宿りした、あとをついていった、などが翌日以降の接近や譲渡判断へ影響します。重要ログの「なぜ？」は、前日の雨宿りや以前の恩が効いた場合にその因果を表示します。謎の卵はpendingイベントとして保存され、数日後にひびが入る遅延Seedの設計例にもなっています。

## NarrativeGenerator

`Simulation → EventLog → NarrativeGenerator → 観察記` の順に分離しています。NarrativeGeneratorはその日に実際に記録されたイベントだけを選び、観察者・三匹それぞれの視点へ言い換えます。出来事自体は変えず、意味づけだけを変えます。現在はテンプレート式で、後に `NarrativeGenerator.create()` の入力をAI APIへ渡せば差し替えられます。

## 保存と現在の到達点

localStorageへ日数、三匹の状態とDNA、記憶、関係、遅延イベント、世界フラグ、出来事、過去の観察記を保存します。現状は「Seed選択 → 認識 → 個体ごとの判断 → 関係が変わる出来事 → 記憶 → 翌日の判断 → 観察記」という循環を実装済みです。目的地オフセットとパーソナルスペース処理により、同じ対象へ集まっても完全には重なりません。
