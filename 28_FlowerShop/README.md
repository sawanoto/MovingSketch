# マーパンファクトリー

こげマーパン、クロワッサン、メロンパン、食パン、ピザマーパンの5種類を6個ちょうど箱詰めして出荷する、モバイル向け配置パズルです。

## 遊び方

1. 下部に並ぶ3つの手持ちトレーから選びます。各トレーには1～5個のマーパンが入り、使ったトレーはすぐ新しいものへ補充されます。
2. 盤面の明るい空きマスを選んで配置します。PCではドラッグ＆ドロップも可能です。
3. 上下左右につながったトレー内で、同色が6個ちょうどになると自動出荷されます。
4. 出荷すると得点とコインを獲得し、周囲の箱へダメージを与えます。
5. 7個以上つなげると出荷されないため、別グループとして分ける判断が必要です。
6. 空きマスがなくなるとゲームオーバーです。

## 静的版

ゲームサーバーへそのまま配置できる、依存関係のない静的版をルート直下に用意しています。

- `index.html`
- `style.css`
- `marpan.css`
- `game.js`

`index.html`を直接開くか、このフォルダを静的HTTPサーバーで公開してください。

