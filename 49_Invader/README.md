# 49_Invader — マーパン・ミュージックインベーダー

敵へ音符を当てた瞬間の音だけで童謡を演奏する、縦方向の音楽シューティング試作です。

## 操作

- `←` / `→`: マーパンを左右へ移動
- `A` / `S` / `D` / `F` / `G` / `H` / `J` / `K`: ド〜高いドのレーンへワープ
- 画面下の鍵盤をクリック／タップ: 対応レーンへワープ
- `SPACE`: 音符を1発発射（押しっぱなしの自動連射なし）

## 初期収録曲

- きらきら星
- メリーさんのひつじ
- ちょうちょう
- ぶんぶんぶん
- 歓喜の歌（ベートーヴェン）
- 交響曲第5番《運命》（ベートーヴェン）

敵を撃ち逃してもペナルティやゲームオーバーはなく、その音だけが演奏から抜けます。エネミーマーパンの正式デザインは `drawEnemyMarpan()`、曲は `SONGS` から差し替え・追加できます。
