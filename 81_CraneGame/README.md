# MAR-PAN CATCHER

「きらきら星」をお手本として聴きながら、自由に鍵盤を演奏し、音程で横位置、リズムの精度で奥行きを操作するUFOキャッチャーです。

`index.html` をブラウザで開いて遊べます。鍵盤クリックまたは `A S D F G H J K` を使用します。

- 8音 = 8列の横位置（演奏した音に合わせて横移動）
- どの音でも開始可能。同じ音の連続ならまっすぐ、旋律なら左右に揺れながら移動
- タイミングが外れても少し進み、GOOD / GREAT / PERFECTでは大きく前進
- PERFECT / GREAT / GOOD / MISS に応じて進む距離が変化
- クレーン直下の影と接触している景品だけを掴み、搬送中は落とさず獲得
- 影が景品に接触していない場合は「からぶり」
- 景品は `shared/marpan-25d.js` の共通形状・目の比率に準拠
- 操作履歴がそのまま音のフレーズとして残る
