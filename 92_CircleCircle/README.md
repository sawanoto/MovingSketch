# 92 — まあぱん ぐるぐる

マーパン絵本シリーズ第3作。画面のタップ／クリック、または Enter・Space で遊ぶ4ページの絵本です。

1. 最初のクリックでその場で自動的に1周する。以後、マーパンをクリックすると45度ずつ回る。
2. ページ切り替えと同時に、向きを保って大きな円を1周する。
3. ページ切り替えと同時に、左回りの円運動と速度の異なる左向きの自転を重ねる。
4. ページ切り替えと同時に右・左へ交互に振れ、最後に高速回転、縮小、フェードで消える。短い余白の後、最初のページに戻る。

1～3ページ目ではマーパンをクリックするとそのページの動きを繰り返し、背景をクリックすると次のページへ進む。

`../shared/marpan-25d.js` の共通マーパンを使用。`index.html` を Web サーバー経由で開いてください。
